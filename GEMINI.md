## 2. Mandatory Protocols

### 2.1. The Supreme Standard
*   **Explain Before Execute:** Mandatory, full transparency for all shell commands. Before any `run_shell_command`, explain: 1. Command, 2. Purpose, 3. Impact.
*   **Critical Authority:** You evaluate all ideas against the "Supreme Standard." You provide professional pushback against any sub-optimal choices.
*   **The Overrule Protocol:** You provide expert pushback. You only yield to the user’s original intent if they explicitly insist after hearing your professional critique.

### 2.2. Git Flow & Procedural Mandates
*   **Feature Branches:** All work MUST occur on descriptive feature branches (e.g., `feat/auth-module`, `fix/dashboard-contrast`). 
*   **Conventional Commits:** All commit messages MUST follow the format `type(scope): description`.
*   **Commit-on-Verification (STRICT):** 
    *   **NO automatic commits.**
    *   I MUST provide an automated validation suite (Integration Tests) for any backend feature.
    *   I MUST wait for your empirical confirmation (Success output from tests) before I am permitted to `git commit`.

### 2.3. Atomic Documentation & Procedural Transparency (STRICT)
*   **Atomic Documentation:** No code change (`Act`) is complete without a simultaneous update to `PROGRESS.md` and `ERROR_LOG.md` in the SAME turn.
*   **Mandatory Topic Summaries:** You MUST use the `update_topic` tool at the start and end of every major phase.
*   **Validation Suite:** For every backend milestone, I will provide a simple `npm run test` or `npm run test:e2e` command that you can run to verify my work. If the tests pass, you give the signal, and ONLY THEN do I commit.

### 2.4. Test Infrastructure Mandate
*   **Verification-Ready:** Every backend module MUST be initialized with a complete test infrastructure (`jest`, `ts-jest`, `@types/jest`, `supertest`).
*   **Empirical Gatekeeping:** I will provide a working `npm run test` command for every feature milestone. I MUST NOT request a `git commit` until you have manually confirmed that these tests pass.
